# Showtime Polymaths

Notes from first principles: physics, robotics, machine learning and whatever comes next. Each chapter is written from scratch and laid out like university course notes, with interactive figures you can play with.

**Live site:** https://arlou022.github.io/showtime-polymaths/

## What's here
- `index.html`: home page (subjects)
- `physics/`: Physics topics and chapters
- `assets/css/`: styling (`notes.css` is the course-notes look)
- `assets/js/catalog.js`: the list of every subject, topic and chapter; add new content here
- `assets/js/fig-kit.js` + `assets/js/figures/`: the interactive figures (one file each)

## Run it locally
Double-click `index.html`, or run `start.bat` to serve it at http://localhost:8000.

No build step: it's plain HTML, CSS and JavaScript. Equations use KaTeX from a CDN.
